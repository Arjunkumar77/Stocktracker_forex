# Gold & Forex Tracker (XAUUSD / GBPUSD)

A complete two-part app:

- **`backend/GoldForexApi`** — a .NET 8 API that keeps one live websocket
  connection open to Finnhub and streams real-time XAUUSD (gold) and
  GBPUSD prices to as many app instances as connect to it.
- **`flutter_app`** — a dark-themed, TradingView-style Flutter app (Android)
  that shows live prices, sparklines, and a full live chart per instrument.

No login, no database — just live prices, kept simple.

---

## Part 1 — Get a free Finnhub API key

1. Go to https://finnhub.io/register and create a free account.
2. Copy your API key from the dashboard.
3. Open `backend/GoldForexApi/appsettings.json` and replace
   `"YOUR_FINNHUB_API_KEY"` with your real key.

Finnhub's free tier includes **real-time** (not delayed) trade data over
websocket for forex pairs via their OANDA feed — that's what gives you
gold and GBPUSD prices with no delay, for free.

## Part 2 — Run the .NET API

Requirements: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
cd backend/GoldForexApi
dotnet run
```

You should see log lines like `Connecting to Finnhub websocket...` then
`Connected. Subscribing to XAUUSD and GBPUSD...`. Leave this running —
it's your live price server.

It listens on **http://0.0.0.0:5000** (both the emulator and a phone on
your wifi can reach it). Quick sanity check while it's running, open in
a browser: `http://localhost:5000/api/health`.

If nothing comes through after a minute, double-check the API key in
`appsettings.json` and look at the console for errors.

## Part 3 — Set up Flutter (from zero)

You said you have no Flutter/Android experience — here's the full path.

### 3.1 Install the tools

1. Install **Flutter SDK**: https://docs.flutter.dev/get-started/install
   (pick your OS — Windows/Mac/Linux — and follow their installer).
2. Install **Android Studio**: https://developer.android.com/studio
   During setup, let it install the Android SDK and a virtual device
   (emulator).
3. Open a terminal and run `flutter doctor`. Fix anything it flags with
   a ✗ (it gives you the exact command/link each time).
4. In Android Studio: **More Actions → Virtual Device Manager → Create
   Device**, pick any modern phone (e.g. Pixel 7), any recent Android
   version, then hit the ▶ Play button to boot the emulator once. Leave
   it running.

### 3.2 Create the Flutter project shell

Flutter projects need platform folders (`android/`, `ios/`, etc.) that
are best generated by the `flutter create` command rather than copied by
hand. Run this once, anywhere you like:

```bash
flutter create gold_forex_tracker
```

This gives you a full working project with a default counter app.
Now replace its guts with the ones provided here:

1. Delete the generated `gold_forex_tracker/lib/main.dart`.
2. Copy everything from this download's `flutter_app/lib/` folder into
   `gold_forex_tracker/lib/`.
3. Copy this download's `flutter_app/pubspec.yaml` over the generated one
   (this adds the `web_socket_channel`, `http`, and `fl_chart` packages).

Then, from inside `gold_forex_tracker/`:

```bash
flutter pub get
```

### 3.3 Allow the app to reach your local dev API (cleartext HTTP)

Android blocks plain `http://` traffic by default — we need to allow it
for local development (our API isn't using https yet).

1. Create the folder `android/app/src/main/res/xml/` inside your Flutter
   project if it doesn't exist.
2. Copy this download's `flutter_app/android_setup/network_security_config.xml`
   into that folder.
3. Open `android/app/src/main/AndroidManifest.xml` and inside the
   `<application ...>` tag add:

   ```xml
   android:networkSecurityConfig="@xml/network_security_config"
   android:usesCleartextTraffic="true"
   ```

   So it looks something like:

   ```xml
   <application
       android:label="gold_forex_tracker"
       android:networkSecurityConfig="@xml/network_security_config"
       android:usesCleartextTraffic="true"
       android:icon="@mipmap/ic_launcher">
   ```

### 3.4 Point the app at your API

Open `lib/services/price_service.dart`. Near the top:

```dart
static const String host = '10.0.2.2';
static const int port = 5000;
```

- **Running on the Android emulator** (from step 3.1): leave `host` as
  `'10.0.2.2'` — that's the emulator's special alias for your computer's
  `localhost`. No change needed.
- **Running on a real phone**: your phone and computer must be on the
  same wifi. Find your computer's LAN IP (Windows: `ipconfig`, look for
  IPv4 Address; Mac/Linux: `ifconfig` or `ip a`, look for something like
  `192.168.x.x`) and set `host` to that, e.g. `'192.168.1.42'`. Also add
  that same IP as a `<domain>` entry in `network_security_config.xml`
  (there's a commented example line already in that file).

### 3.5 Run it

With `dotnet run` still running in another terminal (Part 2), and your
emulator booted (or phone plugged in with USB debugging enabled):

```bash
flutter run
```

Pick your device if prompted. First launch takes a minute or two to
build. You should see the **Markets** screen with XAUUSD and GBPUSD
cards, live prices ticking in, green/red sparklines, and a pulsing
"Live" indicator. Tap a card for the full live chart with session
high/low/open.

## How the "no delay" part works

```
Finnhub (real-time trade feed)
        │  one persistent websocket connection
        ▼
.NET API (FinnhubPriceStreamService + PriceBroadcaster)
        │  fans out to every connected client instantly
        ▼
Flutter app  ── ws://<host>:5000/ws/prices  (live push, not polling)
```

The API keeps exactly one upstream connection to Finnhub no matter how
many phones are using the app — each new tick is pushed to every
connected client the moment it arrives, so there's no polling delay on
either hop.

## Troubleshooting

- **Cards stuck on "--"**: check the `dotnet run` terminal — if it never
  logged "Connected", your Finnhub API key is likely wrong or not saved.
- **Emulator can't connect but health check works in browser**: make
  sure the API's console shows it's listening on `0.0.0.0:5000`, not
  `localhost:5000` (the provided `launchSettings.json` already sets
  this — don't remove `applicationUrl`).
- **Physical phone can't connect**: firewall on your dev machine may be
  blocking incoming connections on port 5000 — allow it, or temporarily
  disable the firewall to test.
- **Prices flatline for the pair markets are closed**: forex/gold trade
  nearly 24/5; outside those hours (weekend) Finnhub simply won't send
  trades until the market reopens — that's expected, not a bug.
